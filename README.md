# CDNHunter Pro 🛰️

**کشف، اسکن و ارزیابی هوشمند IPهای CDN برای اندروید**

CDNHunter Pro یک اپلیکیشن اندرویدی متن‌باز است که IPهای لبه CDN را از منابع رسمی پیدا می‌کند، آن‌ها را با آزمایش‌های واقعی TCP/TLS/HTTP می‌سنجد، بهترین گزینه‌ها را رتبه‌بندی می‌کند و نتایج را در قالب‌های سازگار با کلاینت‌های پروکسی — از جمله **شیر و خورشید** — خروجی می‌دهد.

> ⚠️ این ابزار صرفاً یک ابزار تشخیص شبکه است. هرگز VPN نمی‌سازد، ترافیک برنامه‌های دیگر را رهگیری نمی‌کند، گواهی نصب نمی‌کند و هیچ داده‌ای به هیچ سروری ارسال نمی‌کند.

---

## 🩹 تغییرات نسخه ۱.۰.۱ (رفع باگ اسکن خالی)

- **رفع باگ اصلی**: در نصب تازه، جدول بازه‌های IP خالی بود؛ بنابراین اسکن هیچ هدفی نداشت و بدون هیچ خطایی تمام می‌شد (خروجی خالی). اکنون فهرست رسمی بازه‌های CDN (Cloudflare، Google، CloudFront، Azure، Fastly — مجموعاً ~۹۷۰ CIDR) داخل APK همراه برنامه است و در اولین اجرا به‌صورت خودکار بارگذاری می‌شود.
- آستانهٔ تشخیص «آفلاین» اصلاح شد: دیگر نیازی به تیک VALIDATED سیستم‌عامل نیست (روی شبکه‌های فیلترشده این تیک غلط است و باعث refusing به اسکن می‌شد).
- توقف خودکار اسکن فقط وقتی اینترنت واقعاً قطع شود، نه با هر تغییر جزئی شبکه/VPN.
- خطای «هیچ هدفی برای اسکن نیست» پیام درست فارسی/انگلیسی گرفت (قبلاً پیام اشتباهِ خروجی نمایش داده می‌شد) و در این حالت برنامه ابتدا یک به‌روزرسانی زندهٔ بازه‌ها را امتحان می‌کند.
- صفحهٔ نتایج اکنون زنده به‌روز می‌شود؛ لازم نیست اسکن تمام شود.
- فسخ/لغو اسکن اکنون همهٔ پراب‌های در جریان را واقعاً متوقف می‌کند و یک خطای تکی نمی‌تواند برنامه را ببندد.
- روی دستگاه‌های بدون IPv6، بازه‌های IPv6 دیگر نمونه‌برداری نمی‌شوند (صرفه‌جویی در مصرف اینترنت).
- چک‌باکس‌های انتخاب CDN حالا وضعیت واقعی دارند و همهٔ ارائه‌دهنده‌ها قابل انتخاب/حذف هستند.
- توجه: بازه‌های رسمی Akamai در محیط ساخت در دسترس نیست (فیلتر)؛ این ارائه‌دهنده فقط با به‌روزرسانی زنده داخل برنامه پر می‌شود.

## ✨ امکانات

- **موتور کشف ماژولار** با منابع رسمی و تأییدشده از ۶ ارائه‌دهنده:
  Cloudflare، Google Cloud CDN، Amazon CloudFront، Microsoft Azure CDN، Akamai و Fastly
- **ورود دستی**: TXT (هر خط یک IP)، CSV، JSON، محدوده‌های CIDR
- **اعتبارسنجی سخت‌گیرانه**: IPv4/IPv6، فیلتر کامل IPهای خصوصی/رزروشده، حذف تکراری‌ها و محدوده‌های هم‌پوشان
- **موتور آزمایش شبکه مستقل**:
  - TCP با اندازه‌گیری زمان اتصال و تکرار برای پایداری
  - TLS با SNI و **اعتبارسنجی کامل گواهی (هرگز غیرفعال نمی‌شود)**
  - HTTP/1.1 و HTTP/2 با تفکیک خطاهای DNS/TCP/TLS/HTTP
- **موتور SNI مستقل**: آزمایش ترکیب IP×SNI با ثبت نتیجه، TTL و آزمایش مجدد
- **اندازه‌گیری عملکرد**: تأخیر (کمینه/میانه/میانگین/بیشینه)، جیتر، درصد موفقیت، سرعت دانلود (با سقف بایت) و آپلود برای ارائه‌دهنده‌های پشتیبانی‌شده
- **سه حالت اسکن**: سریع / استاندارد / عمیق (با اعتبارسنجی مجدد نامزدهای برتر)
- **توقف و ادامه اسکن** با ذخیره پیشرفت — حتی پس از بسته‌شدن برنامه
- **سقف مصرف داده، حالت فقط Wi-Fi و توقف خودکار هنگام تغییر شبکه**
- **رتبه‌بندی قابل تنظیم و قابل توضیح** با وزن‌های قابل تغییر و دلایل صریح امتیاز
- **خروجی‌ها**: TXT، CSV، JSON، کلیپ‌بورد، اشتراک‌گذاری اندروید، QR Code و **قالب اختصاصی شیر و خورشید (تأییدشده از سورس رسمی)**
- **رابط کاربری مدرن**: Jetpack Compose + Material 3، حالت تاریک/روشن، فارسی/انگلیسی کامل با RTL
- **بدون تبلیغ، بدون مجوز اضافه، بدون سرور** — فقط ۲ مجوز `INTERNET` و `ACCESS_NETWORK_STATE`

## 🏗️ معماری

```
app/src/main/java/com/cdhunter/pro/
├── core/            # مدل‌ها، اعتبارسنجی IP، CIDR، رجیستری CDN، منابع کشف
│   ├── model/       #   مدل‌ها و ScanConfig (سریال‌پذیر برای توقف/ادامه)
│   ├── util/        #   IpValidator, Cidr, RetryPolicy, HostnameValidator
│   ├── registry/    #   تعریف رسمی ارائه‌دهنده‌ها (آدرس‌های تأییدشده)
│   └── source/      #   پارسرهای فرمت رسمی + fetcher با فیلتر امن
├── network/         # TcpTester, TlsTester, HttpTester(OkHttp), SpeedTester,
│                    # ErrorClassifier, NetworkMonitor
├── sni/             # موتور مستقل IP×SNI
├── scoring/         # ScoringEngine (وزن‌پذیر، قابل توضیح) + منطق Verdict
├── scan/            # ScanEngine سه‌حالته + توقف/ادامه + سقف داده
├── db/              # Room: ۹ جدول، DAOها، مهاجرت‌ها
├── repo/            # Settings/Range/Candidate/Result repositories
├── export/          # Exporter خالص + اعتبارسنجی قالب + ExportManager
└── ui/              # Compose: ۱۶ صفحه، تم، RTL فارسی/انگلیسی
```

جریان داده: **منابع رسمی → اعتبارسنجی → Room → نمونه‌گیری CIDR → پروب موازی محدودشده → نتایج/امتیاز → خروجی اعتبارسنجی‌شده**

## 🔨 روش ساخت محلی

```bash
git clone https://github.com/nayrasolcr-arch/CDNHunterPro.git
cd CDNHunterPro
./gradlew :app:assembleDebug      # APK در app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest  # ۶۲ تست واحد
./gradlew :app:lintDebug          # بررسی Lint
```

`local.properties` با `sdk.dir` خودتان بسازید (در `.gitignore` است).

## 📲 نصب APK

1. APK را از [بخش Releases](https://github.com/nayrasolcr-arch/CDNHunterPro/releases) یا Artifacts اکشن‌ها دریافت کنید.
2. در اندروید، اجازه «نصب از منابع ناشناس» برای فایل‌منیجر خود را بدهید.
3. فایل را نصب کنید. برنامه هیچ مجوز حساسی (موقعیت، ذخیره‌سازی، VPN و…) نمی‌خواهد.

## ⚙️ ساخت خودکار با GitHub Actions

Workflow در `.github/workflows/build.yml`:

- روی هر **Push به main**، هر **Pull Request** و **اجرای دستی** اجرا می‌شود:
  Wrapper-validation → Lint → تست‌های واحد → `assembleDebug` → انتشار APK به‌عنوان **Artifact**
- روی **تگ‌های `v*`**: اجرای Release — در صورت وجود Secrets امضا (`RELEASE_KEYSTORE_BASE64`، `RELEASE_KEYSTORE_PASSWORD`، `RELEASE_KEY_ALIAS`، `RELEASE_KEY_PASSWORD`)، APK امضاشده؛ در غیر این صورت APK debug با توضیح وضعیت امضا
- گزارش‌های Lint/تست هنگام شکست به‌صورت Artifact ذخیره می‌شوند
- مجوزها حداقلی (`contents: read` برای build، `contents: write` فقط برای Release)

## 📖 تفسیر نتایج

| برچسب | معنا |
|---|---|
| **سازگاری تأییدشده** | دست‌دهی TLS با گواهیِ **منطبق با SNI** + پاسخ HTTP موفق + آزمایش واقعی ترکیب IP×SNI |
| **نامزد** | زنجیره TCP+TLS+HTTP سالم است اما هنوز ترکیب SNI مشخصی تأیید نشده |
| **قابل‌دسترس اما ناسازگار** | TCP باز است اما TLS/HTTP/گواهی شکست خورده |
| **غیرقابل‌دسترس** | هیچ اتصال TCP موفقی در تلاش‌های متعدد |
| **منقضی** | نتیجه از TTL (پیش‌فرض ۷۲ ساعت) گذشته — آزمایش مجدد لازم است |
| **داده ناکافی** | تلاش‌های کافی برای قضاوت انجام نشده |

> **قانون طلایی:** موفقیت TCP به معنی موفقیت TLS نیست؛ موفقیت TLS به معنی کارکرد CDN Fronting نیست؛ و هیچ‌کدام به‌تنهایی اثبات کارکرد تونل یک کلاینت خاص نیستند. برنامه هرگز پاسخ 403/404 را «اثبات پروکسی» حساب نمی‌کند و هیچ نتیجه HTTPS عادی را «تونل تأییدشده» صادر نمی‌کند.

## 🤝 سازگاری با شیر و خورشید

قالب خروجی «شیر و خورشید» **از سورس رسمی** [`shirokhorshid/shirokhorshid-android`](https://github.com/shirokhorshid/shirokhorshid-android) استخراج و تأیید شده است:

- **فهرست IP** (`CDN Fronting → Custom IP list`): فقط IPv4 (آدرس یا CIDR)، هر خط یکی، جداکننده فاصله/کاما/سمی‌کولن، تکراری‌ها نادیده گرفته می‌شوند — دقیقاً همان‌طور که `TunnelManager.parseCdnFrontingCustomIpCandidates` می‌پذیرد.
- **SNI** (`Custom SNI`): فقط **اولین** نام دامنه معتبر استفاده می‌شود؛ برنامه بهترین SNI تأییدشده را اول قرار می‌دهد.
- کاربر باید در شیر و خورشید پروتکل را روی **`cdn_fronting`** بگذارد.
- ⚠️ **واردکردن خودکار** (نیتنت/اینتینت) پیاده‌سازی یا ادعا **نشده** است؛ انتقال به‌صورت کپی/پیست دستی است. اعتبارسنجی انتها‌به‌انتها با تونل واقعی شیر و خورشید خارج از محدوده این پروژه است و به‌صورت صریح علامت‌گذاری شده.

## 🌍 ارائه‌دهندگان پشتیبانی‌شده

| ارائه‌دهنده | منبع رسمی | وضعیت تأیید |
|---|---|---|
| Cloudflare | `cloudflare.com/ips-v4` و `ips-v6` | ✅ زنده و پارس‌شده |
| Google | `gstatic.com/ipranges/goog.json` | ✅ زنده و پارس‌شده |
| CloudFront | `ip-ranges.amazonaws.com/ip-ranges.json` | ✅ زنده و پارس‌شده |
| Azure CDN | `ServiceTags_Public_*.json` | ✅ زنده (URL هفتگی عوض می‌شود) |
| Akamai | `ipranges.akamai.com/akamai-ipv4.txt` | ⚠️ URL رسمی؛ در برخی شبکه‌ها مسدود است |
| Fastly | `api.fastly.com/public-ip-list` | ✅ زنده و پارس‌شده |

هیچ IP بدون شواهد رسمی به ارائه‌دهنده‌ای نسبت داده نمی‌شود؛ واردکرده‌های دستی «Imported / unknown» برچسب می‌خورند.

## 📤 فرمت‌های خروجی

خروجی‌ها قبل از ذخیره/اشتراک **دوباره تجزیه و اعتبارسنجی می‌شوند**. فیلدهای هر نتیجه (۱۶ فیلد): IP، نوع آدرس، ارائه‌دهنده، منبع، زمان آزمایش، نتیجه TCP/TLS/HTTP، تأخیر، جیتر، سرعت دانلود، درصد موفقیت، SNI آزمایش‌شده، وضعیت سازگاری، امتیاز و علت شکست.

- `TXT`: هر خط یک IP (یا `IP|SNI`)
- `CSV`: UTF-8 با RFC 4180 و هدر ۱۶ ستونه
- `JSON`: آرایه از اشیاء با همان ۱۶ فیلد
- `شیر و خورشید`: دو خروجی جداگانه (فهرست IP و SNI) + راهنمای درون‌برنامه‌ای
- `QR`: برای فهرست‌های کوچک (چانک‌بندی تا ۵ کد)

## ⚠️ محدودیت‌های شناخته‌شده

- «تأییدشده» یعنی آزمایش‌های شبکه موفق بوده‌اند، نه تضمین تونل کلاینت خاص
- HTTP/3 پشتیبانی نمی‌شود (محدودیت OkHttp)
- IPv6: اعتبارسنجی و واردکردن کامل؛ اسکن فقط نمونه کوچکی از بلوک‌های عظیم را می‌گیرد
- آدرس فایل Azure هفتگی تغییر می‌کند (قابل ویرایش نیست — در سورس ثابت است؛ در نسخه‌های بعد قابل تنظیم می‌شود)
- Akamai ممکن است در بعضی شبکه‌ها در دسترس نباشد
- اسکن در پس‌زمینه با WorkManager اجرا نمی‌شود؛ اسکن هنگام بستن برنامه متوقف و «قابل ادامه» است
- امضای Release نیازمند تنظیم Secrets توسط کاربر است

## 🔐 حریم خصوصی

- همه داده‌ها فقط در پایگاه‌داده محلی برنامه (Room)
- بدون تلمتری، آمارگیر، تبلیغ و سرور
- لاگ خطاها هرگز توکن/رمز/داده مرور ذخیره نمی‌کند
- پاک‌سازی کامل از: تنظیمات ← پاک‌کردن همه داده‌های محلی
- HTTP روی پورت ۸۰ فقط برای آزمایش دسترس‌پذیری (تنظیم‌شده در `network_security_config`)؛ اعتبارسنجی گواهی TLS هیچ‌جا غیرفعال نمی‌شود
